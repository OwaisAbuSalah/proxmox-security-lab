مكتبة Anthropic Cybersecurity Skills قاعدة معرفة مفتوحة المصدر تحت رخصة Apache 2.0، وفيها 817 مهارة أمن سيبراني موزّعة على 29 مجالاً. كل مهارة مكتوبة بصيغة موحّدة تتبع معيار agentskills.io: ترويسة YAML مختصرة في أعلى الملف تتيح البحث السريع، يليها شرح بصيغة Markdown يوضّح خطوات التنفيذ. الميزة الأهم أن كل مهارة مربوطة بأطر معيارية معروفة مثل MITRE ATT&CK و NIST CSF 2.0 و D3FEND، وهو ما يسمح بقياس التغطية الدفاعية بدل الاكتفاء بوصفها.

النطاق دفاعي بالكامل. كل ما نُفِّذ جرى داخل مختبر معزول نملكه ونملك صلاحية اختباره.

كيف يُنفِّذ الوكيل مهارة؟

المهارات في هذا المشروع لم تُقرأ فحسب، بل نُفِّذت عبر وكيل ذكاء اصطناعي. والريبو مبني لهذا الغرض أصلاً: مجلد .claude-plugin يسجّله كإضافة تعمل داخل Claude Code، وكل مهارة تحتوي ملف scripts/agent.py وهو برنامج قابل للتشغيل ينفّذ خطواتها. يقرأ الوكيل ترويسة YAML ليحدّد المهارة المناسبة للمهمة، ثم يشغّل ملف الوكيل بالمعاملات الملائمة ويقرأ المخرجات ويبني عليها قراره التالي.

الوكيل نفّذ، والقرار بقي قراراً هندسياً: اختيار المهارات، وتصميم المناطق، والبديل عند غياب الأداة، وقراءة النتيجة.

المهارات 1–2

01
تقسيم الشبكة باستخدام VLANsConfiguring Network Segmentation with VLANs

تصميم وتطبيق تقسيم الشبكة إلى مناطق معزولة (VLANs) عبر معيار 802.1Q لعزل النطاقات وتقليل مساحة الهجوم ومنع الحركة الجانبية (lateral movement).

  1. تصميم معمارية VLAN حسب المناطق الأمنية (خوادم، إدارة، IoT، ضيوف، DMZ)
  2. تعريف الـ VLANs وربط كل منفذ (port) بالـ VLAN المناسب
  3. إعداد روابط trunk 802.1Q بين المبدلات
  4. تطبيق ACLs للتحكم في التوجيه بين الـ VLANs

02
إعداد قواعد جدار pfSense الناريConfiguring pfSense Firewall Rules

إعداد جدار pfSense الناري: قواعد المرور، سياسات NAT، أنفاق VPN، وتشكيل المرور لفرض العزل بين النطاقات.

  1. تعريف الواجهات (WAN/LAN/VLANs) في WebConfigurator
  2. إنشاء aliases للمضيفات والمنافذ لتبسيط القواعد
  3. كتابة قواعد default-deny ثم السماح المحدد، مع تسجيل الحزم المرفوضة
  4. إعداد NAT / port forwarding للخدمات المكشوفة بحذر

إعداد Suricata لمراقبة الشبكة (IDS/IPS)Configuring Suricata for Network Monitoring (IDS/IPS)

نشر وإعداد Suricata كنظام كشف/منع اختراق مع قواعد Emerging Threats وسجلات EVE JSON للتفتيش اللحظي لحركة الشبكة.

نشر Tailscale كـ VPN بمبدأ Zero TrustDeploying Tailscale for Zero-Trust VPN

نشر Tailscale (مبني على WireGuard) كشبكة VPN متشابكة بثقة صفرية، مع تحكم وصول مبني على الهوية (ACLs) وعقد خروج (exit nodes).

  1. ربط Tailscale بمزوّد هوية (Google/GitHub/OIDC)
  2. تثبيت العميل على الأجهزة وتكوين الـ tailnet
  3. كتابة سياسات ACL دقيقة (من يصل إلى ماذا)

06
تحليل السجلات الأمنية بـ Splunk (SIEM)Analyzing Security Logs with Splunk (SIEM)

استخدام Splunk ولغة SPL للتحقيق في الحوادث عبر ربط السجلات، وإعادة بناء الخط الزمني، وكشف الشذوذ (Windows/firewall/proxy/auth logs).

  1. ابتلاع مصادر السجلات (Suricata EVE، pfSense، Windows Events)
  2. كتابة استعلامات SPL للربط والإحصاء (stats، transaction)
  3. بناء خط زمني للحادثة عبر المصادر
  4. ربط الأنماط بـ MITRE ATT&CK (brute force، pass-the-hash، RDP)

تحليل سجلات DNS لكشف تسريب البياناتAnalyzing DNS Logs for Exfiltration

نشر ملفات الإنذار المبكر (Canary) ضد الفديةDeploying Ransomware Canary Files

نشر ملفات خداعية (canary) تحاكي أهدافاً عالية القيمة في المجلدات، ومراقبتها لحظياً بمكتبة watchdog في Python لإطلاق تنبيه فور أي تعديل/قراءة, إنذار مبكر قبل اكتمال التشفير.

  1. وضع ملفات canary بأسماء جذابة (financial_records.xlsx...) في مجلدات حساسة
  2. تشغيل مراقب watchdog لأحداث نظام الملفات
  3. تصنيف الأحداث (read/modify/rename/delete)
  4. إطلاق تنبيه (email/Slack/syslog) عند أي تفاعل
